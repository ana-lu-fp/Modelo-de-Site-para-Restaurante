# Gourmet & Grill — Restaurante & Steakhouse

## Como usar no VS Code:
1. Extraia o conteúdo deste arquivo ZIP em uma pasta no seu computador.
2. Abra essa pasta no **VS Code**.
3. Instale a extensão **Live Server** (caso ainda não tenha).
4. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.
5. O rodapé possui o link camuflado no ponto final (`.`) ao lado de "Todos os direitos reservados" para acessar o painel administrativo (`admin.html`).
